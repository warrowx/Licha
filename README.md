# Licha (Life + Gacha)

🇬🇧 [Read in English](README.md)

**Licha** - это не просто таск-менеджер, а гача-ежедневник для реальной жизни.
Выполняй задачи, зарабатывай ◆ и крути баннеры с наградами, которые ты сам
вписал: кино, любимый десерт, выходной.

## 📖 О проекте
Идея родилась из желания сделать рутину интереснее. Вместо скучных списков —
азарт, коллекционирование наград и анимации выпадения.

## ✨ Возможности
- **Задачи:** одноразовые и ежедневные, серии, награда зависит от сложности
- **Свои баннеры:** награды 3★/4★/5★, картинки для 4★ и 5★, свои шансы и цена крутки
- **Гарантии (пити):** как в настоящих гача-играх
- **Анимации выпадения:** свечение по редкости, настраиваются в одном файле
- **История круток**
- **Локальное хранение:** данные лежат у вас на компьютере (`%AppData%\GachaLife`)

## 🚀 Как запустить
**Готовая сборка (Windows):**
1. Скачай последний релиз в разделе **Releases**.
2. Распакуй архив и запусти `Licha.exe`.

## 🛠 Стек
C# / .NET, WPF, MVVM (CommunityToolkit.Mvvm), System.Text.Json

## 🧱 Архитектура
- `Models`, `Services` - данные и логика (движок крутки, сохранение), без зависимостей от WPF
- `ViewModels` - состояние и команды страниц (MVVM)
- `Views`, `Animations` - интерфейс и анимации

Логика отделена от интерфейса, чтобы позже перенести приложение на Avalonia.
